if ya want to use my asset -> import DOTween, Zenject, UniTask, Text Mesh Pro and SaintsField cuz there are no support with custom libraries



also asset is using custom debugger (ggDebug), and if you want to see logs you must enable them
How to enable logging?
Go to Edit -> Project Settings -> Player -> Other Settings -> Scripting Define Symbols -> Add (+) -> LOGS_ENABLED -> Apply
